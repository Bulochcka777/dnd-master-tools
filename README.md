# 🎲 DnD Master Tools — Инструменты для Мастера Подземелий

Набор атмосферных браузерных веб-инструментов для Мастера (DM / GM) по настольной ролевой игре **Dungeons & Dragons (D&D 5E 2024 / SRD 5.1)**. 

Работает полностью локально в браузере: **без серверной части, без установок, без внешних зависимостей и сборщиков**.

🌐 **Онлайн-версия (GitHub Pages):** [https://bulochcka777.github.io/dnd-master-tools/](https://bulochcka777.github.io/dnd-master-tools/)

---

## ✨ Основные инструменты

### 🔮 Зеркало миров (`tools/world-mirror/`)
Интерактивный боевой стол для ведения тактических сессий:
* **Поддержка любых карт:** статические изображения (PNG, JPG, WebP) и анимированные видео-баттлмапы (MP4, WebM, GIF).
* **Тактическая сетка:** квадратная и гексагональная (шестиугольники) сетка с точной настройкой шага, толщины, цвета, буквенно-цифровых координат и смещения.
* **Динамический свет:** факелы, костры, магические кристаллы, свечи, лава и порталы с индивидуальной настройкой радиуса, мерцания и скорости анимации.
* **Многослойный туман войны:** кисти открытия и скрытия, мягкие края, а также автоматическое рассеивание тумана источниками света в реальном времени.
* **Режим для игроков:** чистый полноэкранный вывод на второй монитор или ТВ-стол (100% непрозрачный туман без служебных интерфейсов).
* **Сохранение и экспорт:** сохранение карт в файлы проектов `.dndmap` и выгрузка полностью автономного переносимого HTML-файла карты для игроков.

### 🛠️ Верстак картодела (`tools/card-workshop/`)
Единый инструмент для создания и печати игровых карточек формата 9 штук на лист А4 (3×3):
* **Карточки заклинаний:** встроенная база заклинаний D&D 5E 2024 для всех классов с поиском и фильтрами по кругам и школам магии.
* **Карты предметов и артефактов:** конструктор снаряжения, магических предметов и реликвий с выбором редкости и параметров.
* **Двусторонняя печать:** гербовые рубашки карт (для заклинаний и для предметов) с автоматическим выравниванием для идеального совмещения сторон.
* **Умное заполнение:** автоматическое заполнение пустых ячеек листа карточками-памятками или гербовыми заглушками.

### ⚒️ Кузница случайностей (`tools/generators/`)
Генераторы сюжетных деталей и колорита прямо во время партии:
* **Имена:** генерация мужских и женских имён и фамилий для более чем 10 фэнтезийных рас D&D 5E.
* **Города:** генерация названий поселений, их масштаба, особенностей и правителей.
* **Таверны:** колоритные заведения с вывесками, атмосферой, фирменными блюдами и ценами в медных и серебряных монетах.
* **Случайные встречи:** сюжетные зацепки, мирные и боевые столкновения на дороге, в подземелье или дикой местности.
* **Слухи и сокровища:** квестовые сплетни от завсегдатаев и таблицы случайного лута.

### 🧙‍♂️ Генератор NPC (`tools/npc-generator/`)
Детальный генератор неигровых персонажей:
* Быстрое создание полноценной личности: имя, раса, класс, предыстория, мировоззрение.
* Психологический портрет: ведущая черта характера, причуды, манера речи, внешний вид.
* Скрытые мотивы и личная тайна, которую персонаж тщательно скрывает от искателей приключений.
* Возможность сохранения понравившихся персонажей в локальную память браузера.

## 🚀 Быстрый запуск

### Вариант 1: В браузере (GitHub Pages)
Просто перейдите по ссылке:
👉 **[https://bulochcka777.github.io/dnd-master-tools/](https://bulochcka777.github.io/dnd-master-tools/)**

### Вариант 2: Локально на компьютере
Никаких `npm install`, `node` или сборщиков не требуется:
1. Склонируйте или скачайте архив репозитория:
   ```bash
   git clone https://github.com/Bulochcka777/dnd-master-tools.git
   ```
2. Откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Edge, Safari, Яндекс.Браузер).

## 🎨 Технологический стек

* **Стек:** чистый Vanilla HTML5, CSS3 (CSS Variables, Flexbox, CSS Grid) и современный JavaScript (ES6+ Canvas API, Web Animations).
* **Шрифты:** *Cinzel*, *IM Fell English*, *MedievalSharp* (Google Fonts).
* **Хранение данных:** `localStorage` браузера для сохранения проектов и персонажей без необходимости в базе данных.
* **Дизайн:** тёмная фэнтезийная тема D&D с текстурами пергамента, золотыми акцентами и магическим свечением.
